# Mathematical notes

CARE-X inherits the whole-envelope and exact Boolean-lattice attribution viewpoint from Generative Calculus II, but does not claim Möbius inversion, reliability polynomials, minimal cut sets, entropy, or Shannon circuit counting as new mathematics.

The CARE-X-specific contribution is an operational healthcare audit object that jointly records safe workflow feasibility, augmentation dependencies, interaction attribution, degradation survival, minimal enabling sets, minimal failure cuts, and a capability passport.

## Safety strict-refinement proposition
Two assistive systems can have identical workflow-completion rates under every intervention subset while differing in safe-completion envelopes. Therefore completion-only attribution is not complete for deployment safety. A one-case witness is obtained when both systems return the same action, but only one enforces the required human-confirmation rule.
